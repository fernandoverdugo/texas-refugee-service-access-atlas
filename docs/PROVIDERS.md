# Provider inventory

The initial provider inventory contains refugee-specific service locations in Dallas and Tarrant Counties with a current, publicly verifiable organizational source.

## Inclusion rules

A location is included only when:

1. a public source identifies a physical service location;
2. the source identifies refugee-specific services or refugee resettlement activity;
3. the location is in Dallas or Tarrant County for the initial study area; and
4. the source can be preserved in the inventory for later verification.

The inventory does **not** imply that every listed service is open to every refugee, that appointments are available, or that every service category is delivered at all times.

## Current organizations

- International Rescue Committee — Dallas
- Church World Service — Dallas
- Catholic Charities Dallas
- Catholic Charities Fort Worth
- ICNA Relief — Dallas and Fort Worth resource centers
- World Relief Texas — Dallas and Fort Worth

## Address conflicts

Provider addresses can change. **CWS Dallas currently uses 932 S. Greenville Ave, Richardson, TX 75081** in the current CWS local-office directory; an older CWS Dallas overview lists a prior Richardson address. World Relief Texas also has conflicting addresses across some pages and older documents. The inventory uses the address shown on the current local office page and records the discrepancy in the notes field.

This is important for the later routing layer: geocoding a stale address would create false accessibility results.

## Service categories

The first inventory uses broad tags such as:

- resettlement
- case management
- employment
- education
- health support
- cash assistance
- immigration
- family assistance
- resource navigation

These categories will be normalized before accessibility analysis so users can select a service type consistently.
